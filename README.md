# zenmoney-tools

Утилита решает такую проблему:
* Из zenmoney можно выгрузить всю историю операций, но использовать эту историю для анализа без дополнительной обработки невозможно. Например, невозможно отфильтровать движения по конкретному счету, так как при перемещении денег между счетами в выгрузке будет только одна строчка, где сразу из одного счета деньги переносятся на другой.

Что делает утилита:
* Из исходного файла input.csv формирует два выходных файла готовых для анализа

Для запуска утилиты вам потребуется:
* Python (Проверял на 3.14.5)
* Pandas
* openpyxl

Для выгрузки всех операций нужно:
* Открыть мобильное приложение, например для iOS
* Перейти в раздел "Еще"
* Открять "Настройки аккаунта"
* Выбрать пункт "Экспорт операций в CSV"
* Нажать на кнопку "Всю историю"
* Передать файл себе на компьютер

Как использовать утилиту:
* Переименовать файл с выгрйзкой в input.csv
* Положить файл input.csv рядом с исходным файлом zenmoney-csv2xlsx.py
* Запустить файл zenmoney-csv2xlsx.py
* Открыть выходной файл с помощью Excel
