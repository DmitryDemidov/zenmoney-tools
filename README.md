# zenmoney-tools

Набор утилит для работы с выгрузками из программы для учета финансов zenmoney.

Для выгрузки всех операций нужно:
* Открыть мобильное приложение, например для iOS
* Перейти в раздел "Еще"
* Открять "Настройки аккаунта"
* Выбрать пункт "Экспорт операций в CSV"
* Нажать на кнопку "Всю историю"
* Передать файл себе на компьютер
